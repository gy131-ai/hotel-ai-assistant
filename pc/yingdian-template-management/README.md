# 营点AI模板管理独立原型

- 入口：`index.html`
- 模板详情：`template-detail.html?id=YD-TPL-001`
- 样式：`styles.css`
- 交互：`app.js`
- 图片资源：`assets/`

## 使用方式

### 公网部署

将本目录中的全部文件保持原有结构，整体上传到任意静态网站托管服务或 Web 服务器目录。公网入口指向 `index.html` 即可，不需要服务端接口、构建工具或数据库。

### 本地转发

直接发送配套压缩包。接收方解压后双击 `index.html`，即可在 Chrome 或 Edge 中离线查看。

## 原型范围

仅包含营点AI模板管理：模板列表、上传模板、模板详情、首次/重新反推、人工确认覆盖、丢弃结果、模板使用说明、模板信息维度修订、发布与停用状态。

反推仅生成模板信息维度候选结果；模板使用说明为选填纯文本，由运营人员独立维护，保存使用说明不会改变信息维度修订号。

创建时维护模板名称、物料类型、模板使用说明和原始参考图，首次反推结果经人工确认后模板信息才完整。创建完成后，基础内容和信息维度可分别维护；未保存或未确认的修改不影响当前已生效内容。修改物料类型后由运营人员决定是否重新反推，不会自动发起任务。

演示数据使用浏览器 `localStorage` 保存在当前域名或本机中。右下角“原型状态”可切换正常、空、加载、错误和无权限状态，并可重置数据。
